Sampling Distribtion – Recap

  • Core ideas:

    • The distribution of \(\widehat{\beta}_{1}\) in repeated samples.

    • Useful in understanding the statistical uncertainty in \(\widehat{\beta}_{1}\).

    • But also a hypothetical construct, not accessible in practice.

  • Analytical approach to a workaround:

    • Make theoretical model assumptions and derive an explicit expression for \({\text{SE}}(\widehat{\beta}_{1})\) for fixed \(x\).

    • Use this to obtain \(\widehat{\text{SE}}(\widehat{\beta}_{1})\) from the (only) observed sample.

    • Also use them to construct confidence intervals for \(\beta_{1}\).

    • Generalizable to other regression parameters in multiple regression problems.

    • But some practical challenges still remain.

      • Not easily generalizable to random \(x\).

      • \(\widehat{\text{SE}}(\widehat{\beta}_{1})\) has its own sampling fluctuations.

      • Not robust to model assumption violations.

Computational Solution – Bootstrap

  • Start with the original sample of size \(n\).

  • Repeat the following process a large number \(B\) times (typically \(B \ge 1000\)):

    • Step 1: Draw a bootstrap sample by resampling \(n\) times from the original sample with replacement at random.
    • Step 2: Fit the regression on this bootstrap sample and record the slope \(\widehat\beta_1^*\).

  • Examine the bootstrap distribution of all \(B\) collected \(\widehat\beta_1^*\) values.

  • The bootstrap distribution mimics both the shape and the spread of the true sampling distribution.

  • However, it gets shifted over to center around the original sample estimate \(\widehat{\beta}_{1}\).

  • This implies, while we can not use it to estimate \(\beta_{1}\), we can use it to estimate the standard error:

\[\text{SD}_{\text{boot}}(\widehat{\beta}_1^{*}) \approx \text{SE}(\widehat{\beta}_1)\]

  • Repeat the following process a large number \(B\) times (typically \(B \ge 1000\)):

    • Step 1: Draw a bootstrap sample by resampling \(n\) times from the original sample with replacement at random.

  • This implies, we can also use it to construct confidence intervals using the quantiles of the bootstrap samples \(\widehat{\beta}_{1}^{*}\)’s:

\[ 95\% \text{ CI for } \beta_{1}: [\widehat{\beta}_{1,2.5\%}^{*} , \widehat{\beta}_{1,97.5\%}^{*}] \]

Bootstrap Continued …

  • Why the name ‘bootstrap’? drawn from the expression “to pull oneself up by one’s bootstraps,” which means to improve oneself or achieve success through one’s own effort, without outside help.

Residual vs. Case Bootstrap

When \(x\) values are fixed; resamples residuals (\(\widehat{e}_{i}\)) only.

When \(x\) values are also random (in addition to \(y\));
resamples rows \((x_i, y_i)\) jointly.

Residual vs. Case Bootstrap – Key Differences

Property Residual Bootstrap Case Bootstrap
What is resampled? Residuals \(\hat{e}_i\) Pairs \((x_i, y_i)\)
\(x\) values in replicate Fixed (same as original) Random (from original)
Critical assumption Errors i.i.d. \((x, y)\) pairs i.i.d.
Robust to model misspecification? No Yes
Appropriate when \(x\) is fixed by design? Yes Less natural
Appropriate when \(x\) is random? Less natural Yes
Typical use case Designed experiments Observational studies, survey data
